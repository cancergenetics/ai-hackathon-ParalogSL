## Status summary (latest first)

### 2026-10-28 (18:30) — M5: project complete
Deliverables are in place: the installable CLI (`slparalog setup / predict / train`), curated labels (data/labels/, DATA.md), frozen test model (tag final-model-v1) and release model (results/release/model), and REPORT.md. Headline: on the held-out test set the tool clearly beats identity (T = 0.297 [0.131, 0.395]); it transfers to worm but not Arabidopsis; within identical human screening cells the gain vanishes. The full human proteome runs end to end in 99.8 min with 2.52 GB peak (results/bench/e2e_human.json), and the shipped pipeline reproduces the evaluated scores exactly.

The pre-registered robustness test (D21) shows tolerance to fragments/splits/fusions, equal losses for both methods from missing genes, and a halved human margin under combined degradation. Open items are listed as follow-ups in REPORT.md §10 (ascertainment-robust training, plant panel density, tree-based duplication depth, calibration, more unseen species).

### 2026-10-28 (12:05) — M3/M4: model frozen, single test access done
The frozen tool (GBDT on 73 sequence-only features: self-search similarity/family context + comparative features from an 80-species proteome panel) **clearly beats sequence identity on the held-out test set**: T = 0.297 [0.131, 0.395] (human AP 0.349 vs identity 0.106; yeast 0.541 vs 0.190; relative gain 2.1 vs the 0.20 threshold; results/final/final_test.md, a88cff1). It also beats B2 (identity + family size + closest flag) in both species, and transfers to the unseen nematode (worm AP 0.358 vs 0.180, ΔAP 0.178 [0.064, 0.349]). A model trained on yeast only still lifts human AP from 0.106 to 0.259, so a large part of the signal is transferable biology (conservation / single-copy-ortholog / relative-rate features from the panel).

Limits found by the pre-declared secondaries: within identical human screening-ascertainment cells the gain vanishes (−0.020 [−0.098, 0.060]) and in the ≥3-studies stratum it is +0.077 [−0.046, 0.192]; i.e. part of the human headline ranks pairs between screening designs (adversarial dev review D17 predicted this). Unseen Arabidopsis shows no gain over identity (strict −0.005 [−0.111, 0.097]; broad +0.021 [−0.023, 0.062]); the yeast test B1 (0.190) is far below dev (0.567) — cause unexplained (results/splits/split_summary.json shows no yeast group was forced into dev, correcting an earlier note here; group composition differs) and not investigated after the access; the yeast CI is wide. Remaining: human runtime/memory benchmark on an idle machine, release refit on dev+test labels, retro, REPORT.md.

### 2026-10-28 — M1 complete (data, labels, splits frozen); M2 under way
M1 delivered the data foundation with three review rounds behind it (DESIGN v3 + D4–D11). Per-gene proteomes for six species (human 20,770 genes, yeast 6,071), an 80-species reference panel built by an explicit rule (1.55 M proteins), and an Ensembl Compara 116 label universe. Labels are built from primary tables with pre-registered configs committed before any label code, and each passed an independent review (ACCEPT WITH FIXES, no label changes): human primary 205 positives / 7,026 negatives within the universe (12/12 published counts reproduced), yeast 104 / 2,049 (exact re-implementation by the reviewer agrees on 9.1 M pairs). Sealed unseen-species tests: Arabidopsis 51/107 (strict), C. elegans 16/120; S. pombe unavailable. Splits are homology-grouped with labelled pairs contracted, frozen at test fraction 0.40; the primary comparison is pre-declared underpowered (power 0.59 at ΔAP 0.04).

Risks carried forward: human label ascertainment (n testable lines alone gives AUPRC 0.127 vs prevalence 0.027) → pre-declared baseline B4 and stratified reporting; one test-discipline incident (a reviewer computed an unrecorded identity AP on unsplit labels, D10). M2 is in progress: caller + Tier A done (694k human pairs; Compara recall 89%), runtime fix for the capped-query rule, Tier B panel features, PLM embeddings and the dev evaluation harness running. Low Power Mode was switched off by the user at 09:42 on 2026-10-28; timings before that carry lowpowermode=1, and the reported human runtime/memory benchmark must be re-measured on an otherwise idle machine with lowpowermode=0.
